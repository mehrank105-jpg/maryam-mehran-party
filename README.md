# مریم و مهران · مهمونی ۷ آبان

کارت دعوت: https://mehrank105-jpg.github.io/maryam-mehran-party/

## نسخه آماده نظرسنجی

فرم انیمیشنی و آمار میزبان برای GitHub Pages آماده شده‌اند. راه‌اندازی Supabase، آزمایش ذخیره واقعی و تغییر دکمه نظرسنجی هنوز به دسترسی ابزارهای Supabase نیاز دارند. این شاخه نسخه فعال نظرسنجی نیست.

- «میام» مستقیم به نام، شام و نوشیدنی می‌رود.
- «نمیام» یک سؤال بامزه تأیید می‌پرسد؛ پاسخ نهایی منفی فقط نام را ثبت می‌کند.
- جوجه / کباب کوبیده؛ مشروبات الکلی / غیرالکلی لطفاً.
- مجموعه تازه `party_rsvps_v2`؛ هیچ پاسخ قبلی وارد نمی‌شود.
- ثبت مجدد در همان مرورگر پاسخ همان مهمان را اصلاح می‌کند.
- تأیید ثبت تنها پس از دریافت همان رکورد از پایگاه داده نمایش داده می‌شود.
- آمار شامل نام‌ها، حضور، تعداد هر شام و هر نوشیدنی است.

## اجرا و بررسی

Node 22.13 یا جدیدتر و pnpm 11.25.0:

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm dev
pnpm build
```

تنظیمات عمومی را از `.env.example` به `.env.local` کپی کنید. خروجی استاتیک در `rsvp/` ساخته می‌شود. فایل اصلی `index.html` و عکس تأییدشده مستقل از این ساخت باقی می‌مانند.

## راه‌اندازی سرور پس از اتصال حساب

1. ساخت پروژه رایگان Supabase و کلیدهای publishable / secret.
2. اجرای `supabase/schema.sql` با ابزار execute_sql؛ فعال‌بودن RLS و نبود دسترسی anon/authenticated بررسی شود.
3. تنظیم `RSVP_SESSION_SECRET` تصادفی، `RSVP_ADMIN_TOKEN_HASH` برابر SHA-256 کد مدیریت تصادفی ۳۲ بایتی، و `RSVP_ALLOWED_ORIGINS=https://mehrank105-jpg.github.io` در محیط Edge Function.
4. انتشار تابع `party-rsvp` با `verify_jwt=false`. کنترل هویت مهمان و میزبان در خود تابع اجرا می‌شود.
5. ساخت فرم با URL واقعی تابع و **فقط** publishable key؛ کلید secret، کد مدیریت و راز امضای مهمان در گیت ذخیره نمی‌شوند.
6. آزمایش واقعی دو مرورگر، اصلاح پاسخ، رد دسترسی مهمان به آمار و تطبیق جمع غذا/نوشیدنی با پاسخ‌ها؛ سپس انتشار خروجی و اصلاح لینک کارت.
7. بررسی advisors و تهیه مهاجرت رهگیری‌شده با `supabase db pull` پس از تأیید ساختار.

رابط آمار `/maryam-mehran-party/rsvp/#stats` است و کد مدیریت می‌خواهد. لینک ورود میزبان می‌تواند کد را در fragment تحویل دهد؛ کد بلافاصله از نوار آدرس حذف می‌شود و فقط در sessionStorage همان مرورگر نگه داشته می‌شود. کد تنها اجازه خواندن آمار همین نظرسنجی را دارد؛ کلید دیتابیس نیست. دوست‌ها به حساب یا ثبت‌نام نیاز ندارند.

## وضعیت بررسی

۷ آزمایش منطق ثبت پاسخ و کنترل دسترسی موفق بوده‌اند. build و بررسی TypeScript موفق بوده‌اند. ذخیره در Supabase واقعی و انتشار نظرسنجی هنوز انجام نشده‌اند.
